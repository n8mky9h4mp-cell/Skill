# 发布前检查

完成初稿后检查一次，压缩后再检查一次。最多两轮。

## 技术与事实

- [ ] 版本、模型、平台、API、参数和命令有可靠依据
- [ ] 代码、提示词和预期结果自洽
- [ ] 已测试、资料整理、建议尝试和作者判断已区分
- [ ] 没有虚构数据、结果、经历、引用或用户反馈
- [ ] 参考资料直接支持正文关键结论

## 内容效率

- [ ] 开头快速进入问题或结论
- [ ] 文章只围绕一个核心问题
- [ ] 每段只表达一个重点
- [ ] 已删除重复结论、空泛铺垫和常识性展开
- [ ] 结尾没有重复全文
- [ ] 没有为了篇幅增加背景和术语

## 类型闭环

- [ ] 教程可以按步骤完成目标，并说明高频失败原因
- [ ] 原理分析讲清关键机制和边界
- [ ] 故障复盘覆盖证据、根因、修复和预防
- [ ] 评测说明测试条件、成本及适用范围
- [ ] AI 创作实践给出工作流、关键设置、完整提示词和限制
- [ ] 提示词分享标明工具、模型、完整提示词和可替换变量

只检查当前文章对应的类型。

## 公众号排版

- [ ] 标题少而明确，段落适合手机阅读
- [ ] 代码块和提示词块完整且不过度冗长
- [ ] 没有连续加粗、密集列表或装饰性符号
- [ ] Markdown 与公众号排版稿内容一致
- [ ] 标题、摘要、封面提示词和互动语与正文一致

## 图片

- [ ] 每张图片都有解释、证明或比较作用
- [ ] 图片占位与配图清单编号、位置一致
- [ ] 截图、对比图和生成结果来自真实素材
- [ ] 网络图片已提示来源与授权风险
- [ ] 没有必要配图时已省略占位和清单

## 保存

- [ ] 已在当前工作区的 `articles/` 下创建日期与短标题目录
- [ ] `article.md`、`wechat.md` 和 `assets.md` 职责清楚、内容完整
- [ ] 目录名已清理不安全字符并限制长度
- [ ] 同名目录已追加数字后缀，没有覆盖旧文章
- [ ] 无正文配图时，`assets.md` 仍包含封面图提示词
- [ ] 保存成功后，对话只返回摘要、文件链接和校验结果
- [ ] 保存失败时没有写入 Skill 安装目录，并已回退到完整对话输出

## 文风与风险

- [ ] 表达像一线实践者，不像营销稿
- [ ] 没有 AI 腔、故作深刻或强行幽默
- [ ] 限制、适用边界和技术取舍明确
- [ ] 不使用破折号作为装饰性表达
- [ ] 已提示必要的版权、肖像、声音克隆、隐私或平台风险

若任何关键项无法通过，修正文稿。两轮后仍无法确认事实时，列出缺口并停止扩写。
