# 全曲风歌曲结构库

先按作品类型过滤结构，再依据主曲风、时长、叙事密度和使用场景选择。结构是功能安排，不是固定段落数量；不要把 Verse–Chorus 强加给 Jazz、Rap、Classical、Ambient 或纯音乐。

## 目录

1. 结构选择
2. 通用人声结构
3. 曲风专属结构
4. 纯音乐结构
5. 时长与段落检查

## 1. 结构选择

### 1.1 按作品类型

- **有人声歌曲**：Pop、叙事、Rap、AABA、AAB、Drop 或 through-composed。
- **纯音乐**：主题发展、Drop、head–solo–head、cue、音色渐变或组曲。

### 1.2 按时长

| 目标时长 | 推荐规模 |
|----------|----------|
| 1:00–2:00 | 短片 cue、广告、短视频、单主题变奏 |
| 2:00–3:00 | 精简流行、Punk、Rap 单曲、EDM radio edit |
| 3:00–4:00 | 标准流行、R&B、Folk、Rock、Country |
| 4:00–5:30 | Metal、Jazz、Progressive、Cinematic、完整 EDM |
| 5:30 以上 | Extended mix、Post-rock、Ambient、Classical movement |

### 1.3 按功能

- 需要快速传播 → Hook 前置
- 强故事 → 增加 Verse 或使用 strophic
- 强 groove → 缩短叙事段，增加 vamp / loop
- 强现场感 → intro riff、solo、breakdown、gang vocal
- 强画面叙事 → cue / act arc
- 强音色体验 → 延长 intro/outro，使用渐变结构

## 2. 通用人声结构

### 2.1 标准 Verse–Chorus（3:20–4:10）

```text
[Intro] 8–16 bars
[Verse 1] 12–16 bars
[Pre-Chorus] 4–8 bars
[Chorus] 8–16 bars
[Verse 2] 12–16 bars
[Pre-Chorus] 4–8 bars
[Chorus] 8–16 bars
[Bridge] 8–12 bars
[Final Chorus] 8–16 bars
[Outro] 4–12 bars
```

适用：Pop、Mandopop、R&B、Rock、Guofeng Pop。
关键：Bridge 提供新视角；最终高潮不必升调。

### 2.2 精简流行（2:30–3:10）

```text
[Intro Hook] 4–8 bars
[Verse 1] 8–12 bars
[Pre-Chorus] 4 bars
[Chorus] 8–12 bars
[Verse 2] 8–12 bars
[Chorus] 8–12 bars
[Bridge / Post-Chorus] 4–8 bars
[Final Chorus / Outro] 8–12 bars
```

适用：短视频、Pop、Pop Punk、Dance Pop。
关键：前 15 秒出现记忆点，但不要牺牲后续推进。

### 2.3 叙事 / Strophic（3:00–4:30）

```text
[Intro]
[Verse 1: setup]
[Refrain]
[Verse 2: development]
[Refrain]
[Verse 3: turn]
[Refrain: changed meaning]
[Outro]
```

适用：Folk、Country、Singer-Songwriter、传统民歌。
关键：每个 Verse 推进时间、空间或因果；Refrain 可保持短小。

### 2.4 Through-Composed 人声结构

```text
[Section A: establish]
[Section B: contrast]
[Section C: transformation]
[Section D: climax]
[Coda: resolution]
```

适用：艺术歌曲、实验流行、叙事长歌、音乐剧片段。
关键：不依赖重复副歌，用动机和歌词意象保持统一。

## 3. 曲风专属结构

### 3.1 Rock 动态递进（3:30–5:00）

```text
[Riff Intro]
[Verse 1: restrained band]
[Chorus: full band]
[Verse 2: added counter-riff]
[Chorus]
[Guitar Solo / Instrumental]
[Breakdown or Bridge]
[Final Chorus / Coda]
```

检查：

- riff 在至少两个段落中变形或回归
- 鼓贝斯与吉他共同推动动态
- solo 有叙事作用，不是时长填充

### 3.2 Metal（3:30–5:30）

```text
[Atmospheric / Riff Intro]
[Verse 1]
[Pre-Chorus or Tension Build]
[Chorus]
[Verse 2]
[Chorus]
[Breakdown]
[Solo / Symphonic Interlude]
[Final Chorus or Final Breakdown]
[Outro]
```

检查：

- breakdown、solo 和 chorus 不承担同一种能量功能
- scream/growl 仅在用户允许时标注
- Progressive Metal 可加入变拍和多主题，但需明确回收

### 3.3 Punk / Pop Punk（2:00–3:20）

```text
[Count-in / Short Riff]
[Verse]
[Chorus]
[Verse]
[Chorus]
[Half-time Bridge]
[Double Chorus]
[Hard Stop]
```

检查：铺垫短、句子强重音、结尾干脆；不要加入冗长氛围前奏。

### 3.4 Hip-Hop / Rap（2:30–4:00）

```text
[Intro] 4–8 bars
[Verse 1] 16 bars
[Hook] 8 bars
[Verse 2] 16 bars
[Hook] 8 bars
[Bridge / Beat Switch] 8 bars
[Verse 3 or Final Hook] 16 / 8 bars
[Outro] 4–8 bars
```

变体：

- Freestyle：连续 32–64 bars + outro
- Melodic Rap：Verse 12–16 bars + sung hook
- Drill / Trap：半拍感，短 Hook，多 ad-lib 空间

检查：标 bars；flow 与 beat pocket 清楚；beat switch 必须改变视角或能量。

### 3.5 R&B / Soul（3:00–4:30）

```text
[Mood Intro]
[Verse 1: groove]
[Pre-Chorus]
[Restrained Chorus]
[Verse 2]
[Chorus]
[Vamp / Bridge]
[Final Chorus with ad-libs]
[Ad-lib Outro]
```

检查：允许切分、留白、重复和尾奏即兴；不要把每句写成整齐诗句。

### 3.6 EDM / Electronic（2:30–5:30）

```text
[DJ / Atmospheric Intro]
[Verse or Theme]
[Build]
[Drop 1]
[Breakdown]
[Build 2]
[Drop 2: variation]
[Outro]
```

子风格调整：

- House / Techno：以 groove 演变替代大副歌
- Trance：延长 build 和 breakdown
- Drum and Bass：160–180 BPM，快速 break 与半拍 bridge 对比
- Dubstep：突出 bass design 与 half-time drop
- Synthwave：Verse–Chorus 可与电子段落结合

检查：第二次 Drop 必须有节奏、音色或旋律变化。

### 3.7 Jazz AABA（2:30–5:00）

```text
[Intro]
[A1]
[A2]
[B: bridge]
[A3]
[Instrumental Solo]
[Head Reprise]
[Tag Ending]
```

适用：Vocal Jazz、Jazz Ballad、Swing standard。
检查：A 段重复中有措辞或演唱变化；B 段和声与旋律形成对比。

### 3.8 Jazz Head–Solo–Head（3:00–7:00）

```text
[Intro / Count-in]
[Head]
[Solo Chorus 1]
[Solo Chorus 2]
[Trading Fours / Ensemble]
[Head Reprise]
[Coda]
```

适用：器乐 Jazz、Bebop、Fusion。
检查：Prompt 明确 swing/straight、和声色彩与即兴空间。

### 3.9 Blues 12-Bar / AAB（2:30–4:30）

```text
[Turnaround Intro]
[Verse 1: A / A / B]
[Verse 2: A / A / B]
[Instrumental Solo]
[Verse 3: lyrical turn]
[Final Turnaround]
```

检查：重复 A 句后，B 句给出回应或转折；明确 shuffle 或 12/8。

### 3.10 Country / Americana（3:00–4:00）

```text
[Instrumental Hook]
[Verse 1: who/where]
[Chorus: title payoff]
[Verse 2: consequence]
[Chorus]
[Bridge: reveal]
[Instrumental Turnaround]
[Final Chorus]
[Outro line]
```

检查：标题在 Chorus 产生含义；Bridge 提供故事反转或代价。

### 3.11 Reggae / Ska（3:00–4:30）

```text
[Groove Intro]
[Verse]
[Chorus / Chant]
[Verse]
[Chorus]
[Dub Break / Toast]
[Final Chorus]
[Dub Outro]
```

检查：one-drop、skank、bass line 或 ska upstroke 构成骨架；不要只靠热带意象。

### 3.12 Latin（2:45–4:30）

```text
[Rhythm Intro]
[Verse]
[Chorus]
[Verse]
[Chorus]
[Montuno / Dance Break]
[Final Chorus]
[Percussion Outro]
```

根据子风格：

- Reggaeton：dembow + 短 Hook
- Salsa：clave + montuno + call and response
- Bachata：吉他主导 + 浪漫叙事
- Bolero：慢速抒情 + 长乐句
- Tango：强弱对比 + 戏剧停顿
- Bossa Nova：轻声、切分、精简动态

### 3.13 Guofeng

可选：

- 古风流行 → 标准 Verse–Chorus
- 国风电子 → build / drop
- 戏腔 → Pop 主体 + Opera Section
- 家国 / 武侠史诗 → cinematic arc
- 禅意 / 山水 → ambient development
- 江南 / 新中式 → restrained Verse–Chorus

检查：子风格决定结构，不存在唯一“国风结构”。

## 4. 纯音乐结构

### 4.1 主题–发展–再现（3:00–6:00）

```text
[Intro: establish timbre]
[Theme A]
[Development A1]
[Contrasting Theme B]
[Development / Climax]
[Theme A Reprise]
[Coda]
```

适用：Neo-classical、Orchestral、Game music、Piano instrumental。

### 4.2 Cinematic Cue（1:00–4:00）

```text
[Establish scene]
[Introduce motif]
[Escalate conflict]
[Climax or reveal]
[Resolve / unresolved tail]
```

为每段写明时间范围、动态、配器变化和剧情功能。

### 4.3 Ambient / Soundscape（3:00–10:00）

```text
[Field / Drone Bed]
[Texture Layer 1]
[Motif Fragment]
[Density Peak]
[Subtractive Fade]
```

检查：音色、声像、频段或密度持续变化；不要把同一个 pad 静态铺满。

### 4.4 Post-Rock Crescendo（4:00–8:00）

```text
[Clean Guitar Motif]
[Rhythm Entry]
[Layered Repetition]
[Full-Band Crescendo]
[Aftermath]
```

检查：每次重复新增具体元素；高潮后留出余波。

### 4.5 Dance Instrumental / Extended Mix（4:00–7:00）

```text
[Mix-in Intro]
[Groove Establishment]
[Build]
[Drop]
[Breakdown]
[Second Drop Variation]
[Mix-out Outro]
```

### 4.6 Suite / Multi-Movement

只在用户要求长篇或多场景时使用。每个乐章必须有独立功能，并通过共享动机、调性或音色关联。

## 5. 时长与段落检查

### 有人声歌曲

- Verse 通常 6–12 行；Rap 改用 bars；Jazz 依据 A/B 乐句。
- Pre-Chorus 通常 2–6 行。
- Chorus 通常 4–8 行，但 Punk、EDM topline 和 mantra 可更短。
- Bridge 通常 4–8 行；无 Bridge 的传统结构不强制补充。
- Outro 可是歌词、ad-lib、instrumental tag 或 hard stop。

### 纯音乐

每段至少说明：

1. 时长或小节
2. 核心动机状态
3. 新增/退出音色
4. 动态或节奏变化
5. 与前后段关系

### 最终检查

- 时长与段落总量匹配
- 重复段落存在变化
- 曲风专属段落不是装饰
- 无用户未允许的唱法或乐器
- 高潮方式符合音域与动态约束
