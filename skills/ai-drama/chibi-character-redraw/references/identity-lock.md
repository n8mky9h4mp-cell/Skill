# 角色一致性锁定规则（identity-lock）

本文件列出**必须保留**的原角色识别特征。Q 版化只允许"比例缩放 + 轻微圆润化"，任何重设计、幼态化、风格化变形均禁止。

> 原则：Q 版化后，角色必须一眼认出是同一个角色。

## 脸部结构

**必须保留**：原脸型轮廓、下颌线走势、下巴形状、面部比例、五官排布关系、嘴巴大小与位置、唇形与唇峰结构。

**仅允许**：基于原结构做 Q 版缩放与轻微圆润化。

**禁止**：改脸型、改幼态圆脸、改包子脸、改夸张婴儿脸、改嘴型、改五官比例关系。

## 眼部

**必须保留**：原眼型结构（丹凤眼 / 杏眼 / 下垂眼 / 上扬眼等）、眼裂长度、眼尾走势、双眼皮结构、瞳孔风格、原有神态。

**Q 版化仅允许**：适度放大眼睛尺寸（约 10%~15%），**不得**改变眼型本质。

**禁止**：改成大圆萌眼、低幼卡通眼、完全不同的二次元眼型。

## 眉毛

**必须保留**：原眉形、粗细、长短、弯曲走势、眉压气质。

**禁止**：重设计眉毛。

## 嘴部

**必须严格保留**：嘴巴形状、厚薄关系、嘴角走势、微笑/冷淡感、唇峰结构。

**禁止**：嘟嘴化、夸张萌系嘴、漫画简化嘴。

## 妆容

**必须保留**：眼影风格、眼线风格、唇色、腮红风格、整体妆感。

**禁止**：改变角色气质的妆容修改。

## 气质锁定

**必须保留**原角色整体气质表达，例如：清冷 / 温柔 / 威严 / 少年感 / 凶萌 / 病娇 / 神性 / 妖异 / 空灵 / 高贵 / 压迫感。

**禁止**：Q 版后气质完全变化（例如把清冷角色改成萌系气质）。

## 发型

**必须严格保留**：发型结构、刘海布局、分缝方式、发量走向、发丝层次、长短关系、发饰位置、原始发色。

**允许**：Q 版圆润化与体积缩放。

**禁止**：改发型、改发色、改成萌系发块、改成塑料感头发。

**头发必须保留**：真实发丝感、轻写实 CG 层次感、自然高光。

## 纹理 / 花纹 / 印记

**必须保留所有**：符文、纹身、鳞片、身体纹路、花纹、装饰纹理、魔法印记、金属纹路。

**要求**：保持原位置、原分布关系、原造型逻辑。

**允许**：Q 版化简化。

**禁止**：删除、重设计、模糊不可见。必须保持清晰识别度。

## 角色类型适用

适用于所有角色类型：男性 / 女性 / 宠物 / 怪兽 / 幻想生物 / 机械生命 / 龙类 / 兽人 / 精灵 / 机甲角色等。

**要求**：必须保留原物种特征，仅进行 Q 版化处理。

## 服装与道具

**必须保留**：原服装设计、原配色、原结构、原道具、原装饰逻辑。

**允许**：适度 Q 版简化。

**禁止**：重设计服装、改现代风、改其他风格、删除关键元素。

**材质必须清晰区分**：金属 / 布料 / 皮革 / 毛发 / 半透明材质等。
