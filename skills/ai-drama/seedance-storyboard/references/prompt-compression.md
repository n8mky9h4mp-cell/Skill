# 提示词压缩策略（≤2000 字）

## 镜头数量分配

| 时长 | 建议镜头数 | 节奏 |
|------|-----------|------|
| 4–6 秒 | 2–3 镜 | 快切或单镜长推 |
| 7–10 秒 | 3–4 镜 | 起承转合完整 |
| 11–15 秒 | 4–6 镜 | 可含小高潮+余韵 |

## 工业级分镜 → 最终提示词映射

| 分镜层保留 | 压缩时删除/合并 |
|-----------|----------------|
| 机位+景别+运镜（1种） | 文学修辞、重复景别 |
| 核心动作链 | 次要背景动态 |
| 光影主方向 | 冗余光影形容词 |
| 关键 SFX（≤2/镜） | 次要环境音 |
| 对白（{}内） | OS/VO 若可合并则合并 |
| 正向 AI 约束（合并到【约束】） | 每镜单独 AI 约束重复项 |

**原则**：分镜供人审阅，提示词供模型执行——信息互补，禁止整段复制粘贴。

## 最终提示词固定结构

```text
画面无任何字幕。

【风格】{风格}，{N}秒，{16:9|9:16}，{氛围一句话}

【镜头】
镜头1：{运镜}+{画面}+{动作}+{<>音效>}+{角色{对白}}
镜头2：...
...

【声音】（配乐风格）+<关键音效>+{声线描述}

【约束】{正向约束合并为一行}

【参考】@图片1 角色锚定（仅有素材时）
```

## 压缩优先级（超 2000 字时按序执行）

1. **删修饰**：去掉「非常」「极其」「仿佛」等空词
2. **合并同场景镜头**：连续动作合并为一镜
3. **删次要音效**：每镜保留 ≤1 个关键音效
4. **缩短约束行**：保留核心 3 项（无文字、主体一致、单运镜）
5. **精简对白**：保留金句，删语气词

每轮压缩后重新计数，直至 ≤2000 字。

## 信息密度技巧

- 用标准术语代替长句：`中景缓慢推近` 优于 `镜头从中景慢慢向人物推近`
- 光影一行定调：`侧逆光，暖金色调，低饱和` 优于分散描写
- 情绪外化一行：`肩膀微颤，眼眶泛红，手指攥紧袖口`
- 英文仅保留专业词：`PBR`、`UE5`、`HDR`、`SSS`、`ray tracing`

## 禁止写入最终提示词

- 完整剧本正文、分镜编号、SFX 标签前缀（用 <> 直接写音效）
- `AI约束：` 字段名（内容并入【约束】）
- 负面词堆砌
- 与【风格】重复的氛围描写

## 字数校验

生成后统计【风格】至【参考】（或【约束】若无参考）之间的总字符数（含标点、不含代码块标记），标注 `字数：{N}/2000`。
