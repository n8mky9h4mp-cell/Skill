# 即梦合规与敏感表述指南

> 2026 年审核趋严。生成前/后各扫描一遍。

## 核心原则

1. **删除所有负面关键词**，一律改用正向描述
   - ✗ `严禁性感` → ✓ `少女俏皮无邪甜美`
   - ✗ `禁止出现字幕` → ✓ `画面干净无文字元素`
   - ✗ `不要血腥` → ✓ `画面聚焦情绪张力与光影氛围`

2. **提示词开头**仅写一句：`画面无任何字幕。` 不写冗长禁令变体

3. **【声音】块**只放声线/配乐/音效，对白嵌入对应镜头内，不重复堆对白

## 高风险题材（改写或提示用户调整）

| 类别 | 处理 |
|------|------|
| 色情低俗 / 过度暴露 | 服装完整、姿态端庄；泳装场景改运动/日常着装 |
| 血腥暴力 | 省略暴力过程，强化结果反馈（光影/声效/反应镜头） |
| 涉政 / 敏感历史 | 避免具体政治符号、旗帜、敏感人物 |
| 封建迷信 / 灵异恐怖 | 改奇幻/科幻设定，或治愈/悬疑非恐怖向 |
| 违法犯罪示范 | 不描写具体作案手法，聚焦后果或正义主题 |
| 未成年人 | 年龄+性别组合中性化；避免不当互动描写 |

## 表述中性化

- 避免：`年轻女孩`、`少女` 与暴露/魅惑语境组合
- 改用：角色名 + 外观特征（「穿青色长裙的女子」）
- 动作戏：不写击打细节，写「身影交错，尘埃扬起，一方踉跄后退」

## 动作戏安全写法

- 省略暴力过程，强化结果反馈
- 危险动作放画外：用光/声/反应表现
- 示例：不写「一刀刺入」，写「刀光闪过，对方跪倒在地，喘息急促」

## 物体交互避坑

- 用「摔/取/递/放下」替代「掰断/剥瓣/撕裂」
- 复杂手部操作拆成可见的简单动作链

## 安全区（用户未指定时的默认倾向）

自然风光、建筑、萌宠、美食、治愈场景、纪录片质感环境片。

## 参考素材合规

- 不支持写实真人脸部素材作参考
- 参考图去除非必要文字后再输入
- 多人参考每组 ≤4 人，分组生成

## 扫描清单（生成后逐项核对）

- [ ] 无「严禁/禁止/不要/绝不」等负面词
- [ ] 无过度暴露、血腥过程、恐怖惊吓特写
- [ ] 无具体政治/宗教敏感符号
- [ ] 未成年人描写中性安全
- [ ] 动作戏无详细暴力过程
- [ ] 开头仅有「画面无任何字幕。」一句
- [ ] 对白在镜头内，【声音】块无对白重复
