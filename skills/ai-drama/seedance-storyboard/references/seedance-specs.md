# Seedance 2.0 平台规范速查

> 即梦 / 小云雀 / LibTV 沉浸式短片，模型 Seedance 2.0 家族。

## 生成参数

| 参数 | 范围 | 说明 |
|------|------|------|
| 单次时长 | 4–15 秒 | 在生成面板选「生成长度」，同时在提示词约束行写明 |
| 画幅 | 16:9 横屏 / 9:16 竖屏 | 面板选 + 提示词约束行双写 |
| 超长视频 | 分段 ≤15s + 延长/拼接 | 延长语法：`向后延长<视频1>，生成…` |

## 提示词字数

| 语言 | 官方建议 | 本 Skill 硬性上限 |
|------|----------|-------------------|
| 中文 | ~500 字宏观最优 | **2000 字**（高密度填满，超则压缩） |

## 核心公式

```
精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质 + 约束条件
```

不要把完整剧本直接当 prompt；喂给模型的分镜 prompt 必须精简聚焦。

## 分镜时序（官方）

- **优先**：`镜头1 / 镜头2 / 镜头3` 按事件顺序，配合相对节奏词（快速/缓慢/随即/片刻后/定格一瞬）
- **避免**：硬写 `0–3秒`（精确秒数支持不稳定，易生成异常）
- **例外**：用户明确要求口型强对齐时，可保留秒数标注

每个镜头写法顺序：
1. 运镜或切换方式
2. 主体动作与表情
3. 位置/空间变化
4. 音频（音效/人声/背景乐）

## 单镜运镜铁律

- 一个镜头尽量只指定 **1 种运镜**
- 同时推拉摇移会增加画面不稳定性

## 符号规范

| 类型 | 符号 | 示例 |
|------|------|------|
| 音乐 | （） | （背景中低沉弦乐渐强） |
| 音效 | <> | <远处雷声滚过> |
| 台词 | {} | 角色用低沉声线说道{快走} |
| 画面字幕 | 【】 | 本 Skill 默认画面无字幕，【】仅剧本层 |

台词语言统一，避免中英混用（专有名词除外）。

## 多模态引用（@语法）

最多 12 个文件：图片 ≤9、视频 ≤3、音频 ≤3。

| 任务 | 句式 |
|------|------|
| 参考图片主体 | `参考<图片N>中的<特征>，生成…` |
| 参考视频运镜 | `参考<视频N>中的运镜/动作，生成…` |
| 参考音频音色 | `参考<音频N>中的音色，生成…` |
| 编辑视频 | 直接用 `<视频N>` 指代，**不写**「参考<视频N>」 |
| 延长视频 | `向后延长<视频1>，生成…` |

**主体定义**：`将<图片N>中的[服饰/发型/外观]定义为<主体N>`，后续全程用同一标签。

**避坑**：
- 不要用人物三视图作参考（易双胞胎/漂移）
- 人脸参考用单独大头照 + 全身照分开绑定
- 多人场景每组 ≤4 人
- 素材过多易风格冲突，推荐 4–5 个功能角色：角色锚定 + 场景定调 + 运镜参考 + 节奏氛围

## 动作描述

- 肢体细化 + 程度量化（缓慢抬手、快速转头）
- 优先低缓连续小动作，规避狂奔、大跳、剧烈翻滚
- 补充动作过渡衔接（借转身惯性顺势抬手）
- 情绪外化代替抽象词（见 SKILL.md 情绪表）

## 画质与约束词

- 画质：高清、细节丰富、电影质感、色彩自然、光影柔和
- 约束正向表述：画面干净无文字元素、主体外观全程一致
- 横屏出字幕概率低于竖屏（需无字幕时优先横屏生成后裁切）

## 延长 vs 分段

| 场景 | 策略 |
|------|------|
| 长对话、情绪递进、单路径移动 | 延长（一镜到底） |
| 追逐、打斗、蒙太奇、场景转折 | 分段生成 + 剪辑拼接 |

延长硬限制：最多 3 段视频输入、总时长 ≤15s。

## 常见问题

| 问题 | 解法 |
|------|------|
| 人物 ID 漂移 | 大头照单独绑定面部，全身照绑定妆造；精准素材放靠前 |
| 双胞胎 | 人物名标注对应图；末尾加「同一画面仅保留单个对应人物」 |
| 多余字幕 | 开头写「画面无任何字幕」+ 约束行正向表述 |
| Logo/水印 | 约束行写「画面干净无水印无标识」 |
| 风格漂移 | 明确风格约束词（2D日漫/3D国风漫画等） |
| 动作崩坏 | 用「摔/取/递」替代「掰断/剥瓣」；打戏省略过程强化结果 |
