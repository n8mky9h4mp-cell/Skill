# 即梦视频提示词拆分器

将完整的分镜脚本拆分为多个适合 AI 视频生成平台（如即梦、Seedance 等）的短视频片段提示词，每个片段时长≤15秒，字数≤2000字。

---

## 一、核心任务

1. 读取用户提供的小说/分镜脚本
2. 按场景/幕次拆分视频片段
3. 每个片段生成完整独立的即梦视频提示词
4. 确保提示词可直接拷贝使用，无冗余内容

---

## 二、拆分原则

### 2.1 时长限制

| 平台 | 最长时长 | 推荐时长 |
|------|----------|----------|
| 即梦 | 15秒 | 10-15秒 |
| Seedance | 15秒 | 10-15秒 |
| 即梦（会员） | 可选更长 | 按需调整 |

### 2.2 字数限制

- 每个片段提示词 **≤ 2000字**（含所有标签）
- 优先控制在 **1500-1800字** 以内，留出余量

### 2.3 片段拆分策略

**优先按场景拆分**：
- 一个场景 = 一个视频片段
- 场景过短则合并相邻场景
- 场景过长则拆分

**拆分判断标准**：
- 场景时长 ≤ 15秒 → 单独一个片段
- 场景时长 > 15秒 → 按剧情自然断点拆分
- 相邻短场景 → 合并为一个片段

### 2.4 严格时长计算规则（必须遵守）

**重要：时长必须严格按照原分镜脚本的时间码计算，禁止估算。**

1. **读取时间码**：从原分镜脚本的每个分镜中提取起止时间（如 `00:00-00:04`）
2. **计算单镜时长**：每个分镜时长 = 结束时间 - 开始时间
3. **片段时长累加**：片段总时长 = 所包含的所有分镜时长之和
4. **精确到秒**：所有时长以整数秒为单位，不四舍五入
5. **总时长核对**：所有片段时长之和必须 = 原分镜脚本总时长
6. **底部统计表**：必须与实际计算结果一致，禁止出现总时长前后矛盾

## 三、输出格式

### 3.1 片段标题格式

```
## 片段X：[片段名称]
**时长**：XX秒
**包含分镜**：分镜X ~ 分镜X
```

### 3.2 提示词格式

每个片段输出**一个完整可一键拷贝的代码块**，包含画面描述 + 音效 + 参数，无需分开复制。

**重要：每个片段的时间轴直接沿用原分镜脚本的全局时间码，不需要从00:00重新计算。** 保持与原分镜脚本时间码一致，方便追溯和核对。

**画面描述中，每个镜头开头必须标注镜头识别信息**，格式为：
```
【分镜X | 00:00-00:04 | 景别：超大全景 | 机位/运镜：航拍俯拍慢推】
```

这样AI生成时能明确知道每个镜头的编号、时间、景别、机位，保证镜头一致性。

```
【画面】
{masterpiece标签}
{画风标签}

【出场角色设定】
{从原分镜脚本的"主体角色统一设定"中，提取本片段所有出场角色的完整设定：性别、年龄、身高、体型、外貌特征、发型、服装、武器、坐骑、特征标记（如泪痣、面具等），确保每个出场角色都有完整的外观描述，不得省略}

【分镜X | 00:00-00:04 | 景别：XXX | 机位/运镜：XXX】
{该镜头的画面描述：角色+动作+场景+光影+氛围}

【分镜X | 00:04-00:08 | 景别：XXX | 机位/运镜：XXX】
{该镜头的画面描述：角色+动作+场景+光影+氛围}

【音效】
{SFX音效列表（含台词：如有台词必须加入音效列表，格式：角色+台词"台词内容"）}

【画质约束】
{画质要求 + AI约束}
```

### 3.3 台词处理规则

**重要：原分镜脚本中的台词/对话/旁白必须100%保留，不得遗漏。**

- **画面描述中**：角色动作描述后追加 `台词："具体台词内容"`，确保AI生成时口型对应
- **音效列表中**：追加 `角色名+台词"台词内容"`，确保音效包含语音
- **无台词的分镜**：正常处理，不添加台词相关内容
- **多句台词**：按出现顺序依次写入

## 四、生成步骤

### 步骤1：读取原分镜脚本
- 识别场景结构
- **提取每个分镜的完整信息：分镜号、时间轴（起止时间）、景别、机位/运镜、镜头描述、SFX、AI约束**
- 统计每个场景/分镜时长
- 提取角色特征
- **提取所有台词/对话/旁白内容，记录出现的分镜位置**

### 步骤2：规划片段拆分
- 确定片段数量
- **根据时间码精确计算片段时长，控制在10-15秒以内，禁止估算**
- 确保剧情连贯
- **台词所在分镜优先完整保留在同一片段中，不拆分跨台词的镜头**
- **计算总时长，验证与原分镜脚本总时长一致**
- **规划每个镜头的识别标签（分镜号、时间轴、景别、机位/运镜）**

### 步骤3：生成片段提示词
- **在【画面】开头、画风标签之后，添加【出场角色设定】部分**
- **从原分镜脚本的"主体角色统一设定"中，提取本片段所有出场角色的完整外观设定（性别、年龄、身高、体型、五官、发型、服装材质、武器规格、坐骑、特征标记如泪痣/面具等）**
- **每个出场角色单独一行描述，确保角色特征完整不遗漏**
- **每个镜头前标注：【分镜X | 时间轴 | 景别：XXX | 机位/运镜：XXX】**
- 提取核心画面描述
- **将台词写入画面描述（角色动作后追加：台词："台词内容"）**
- 组合成完整提示词
- **将台词加入音效列表（格式：角色名+台词"台词内容"）**
- 添加画质约束
- 控制在2000字以内

### 步骤4：质量检查
- **时长是否严格按时间码计算，与原分镜一致**
- 字数是否超限
- 角色特征是否完整
- **台词是否完整保留（画面描述和音效列表中都要有）**
- **总时长是否与原分镜脚本总时长一致**
- 提示词是否可独立生成视频
