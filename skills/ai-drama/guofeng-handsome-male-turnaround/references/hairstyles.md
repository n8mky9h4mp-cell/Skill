# 古风男性发型库

| 发型 | 适用风格 | 细节 |
|---|---|---|
| 高束冠发 | 仙侠、权贵 | 长发整齐束于头顶，以玉冠或金属冠固定，鬓发利落 |
| 半束长发 | 仙侠、玄幻、书生 | 上半束起、下半披落，额前留少量自然碎发 |
| 高马尾 | 侠客、将军 | 发根蓬松，马尾有重量和动势，适合动作感角色 |
| 低束长发 | 书生、谋士 | 发带低束，整体克制温润，颈侧保留细碎发丝 |
| 编发披发 | 敦煌、妖族 | 局部细辫与长发结合，配少量金属或玉石发饰 |
| 墨发散披 | 暗黑、妖族 | 长发披散但结构清晰，发丝遮挡少量面部，避免凌乱结块 |
| 利落短发 | 玄幻、军旅 | 古风与现代国漫融合，发尾整洁，避免现代潮流染烫感 |

## 发色与发质

- 墨黑：通用，逆光带蓝黑或暖棕轮廓。
- 深棕：适合书生、侠客与写实风格。
- 银白：适合仙侠、妖族与暗黑角色，避免老年感。
- 灰蓝黑：适合玄幻与冷峻角色，用作低饱和变化。

描述真实发丝、胎毛、碎发、毛流、重量、透光和接触阴影。冠饰必须符合身份，避免同时堆叠发冠、簪、华胜等多套系统。
