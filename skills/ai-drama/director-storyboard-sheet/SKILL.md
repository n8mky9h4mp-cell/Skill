# 工业级导演分镜故事板生成器

根据输入的分镜脚本内容，自动生成【电影级导演故事板（Storyboard Sheet）】的完整中文提示词，可直接用于 AI 图像生成。

输出结果为完整的中文提示词而非视频画面图片，包含：
- 影视项目提案页
- 导演分镜墙
- 电影预演展示板
- 工业级故事板设计稿

---

## 一、核心任务

1. 读取用户提供的分镜脚本
2. 提取所有分镜的完整信息（镜头号、时间轴、景别、机位、运镜、画面描述、情绪、特效等）
3. 自动计算分镜数量与布局
4. 生成一个完整的导演故事板提示词
5. 提示词可直接复制到 AI 绘图工具生成故事板图片

## 二、全局视觉设定

### 2.1 主体角色统一设定

必须从分镜脚本中提取并完整展示所有主要角色的外观特征，确保故事板中角色形象一致：

| 角色 | 性别 | 年龄 | 体型 | 外貌特征 | 服装 | 武器 | 配饰 | 坐骑 |
|------|------|------|------|----------|------|------|------|------|
| 示例女将军 | 女 | 27岁 | 纤细英武 | 白皙皮肤，柳叶眉杏仁眼，右眼下泪痣，黑色高束长发发尾微卷 | 银色雕纹战甲，白色披风 | 长鞭配腰间佩剑 | 战甲金属拉丝质感 | 雪白战马 |
| 示例神秘少年 | 男 | 外表19岁 | 身形修长 | 面容隐于黑暗，双眼如寒星 | 黑色暗纹长袍 | 背负双剑 | 宽大兜帽 | 驾驭黑龙 |

**必须提取的信息**：
- 性别、年龄、体型
- 面部特征（眉眼、特殊标记如泪痣等）
- 发型、发色
- 服装材质、颜色、特殊元素
- 武器类型、外观、位置（如背负腰间手持等）
- 配饰（披风、面具、头盔、兜帽等）
- 坐骑（如有）

**重要**：武器位置必须明确标注（背负、腰间、手持、斜挎等），同一角色的所有镜头中武器位置必须保持一致。

### 2.4 环境统一设定

必须从分镜脚本中提取并完整展示：

| 环境要素 | 描述 |
|----------|------|
| **地貌** | 连绵沙丘的无垠大漠，蛮族部落（土坯帐篷+石头祭坛） |
| **时间** | 开场正午烈日 → 中段下午 → 末段黑云遮日 |

| **背景元素连续性** | 沙丘形态、沙尘流动方向、天空色温变化有连贯性 |

### 2.5 声音规则（BGM 处理）

必须忠实于原分镜脚本的声音设定，**严禁擅自添加或修改 BGM**：

1. **检测原脚本**：解析原分镜脚本中是否有 BGM / 配乐相关描述。
2. **无 BGM 时**：原脚本若标注"无BGM"，故事板提示词中不得出现任何配乐、背景音乐、BGM 相关描述；底部总结区的"配乐风格"直接标注为"无BGM"即可，无需额外说明。
3. **有 BGM 时**：按原脚本描述的配乐风格如实展示，不得更改类型或扩展。
4. **环境音/Foley/台词**：原脚本中的环境音、Foley音效、台词等内容必须完整保留，真实还原原脚本的声音设计，不得删除或新增。

## 六、每个分镜结构

### 5.1 顶部信息

```

镜头02

```

依次自动编号，时间轴沿用原分镜脚本的时间码。

### 5.2 中部画面

严格根据当前分镜内容生成画面描述，自动解析：

- **角色**：人物外观、服装、发型、武器
- **动作**：肢体动作、表情、运动方向
- **场景**：环境、背景、道具
- **情绪**：氛围、情感基调
- **特效**：光效、粒子、能量等
- **光影**：光线方向、明暗对比、色调
- **镜头语言**：构图、透视、焦距

**画面要求**：
- 角色一致（服装、发型、武器、特征统一）
- 场景连续（环境元素连贯）
- 动作连续（前后镜头动作衔接自然）
- 构图合理（符合景别与机位要求）
- 符合当前镜头描述
- 电影级视觉效果
- **瞳孔画面隔离**：当分镜描述"瞳孔里映出/反射某物"（如瞳孔里映着能量球、远处身影等）时，这些被反射的元素**只能严格限定在瞳孔范围内**呈现，严禁溢出、渗透或出现在瞳孔以外的画面区域。瞳孔外区域仅表现实际场景，瞳孔内为反射成像，两者界限清晰、互不干扰。

### 5.3 底部信息栏

每个分镜下方展示以下信息：

| 字段 | 说明 | 示例 |
|------|------|------|
| **景别** | 自动提取 | 远景 / 全景 / 中景 / 近景 / 特写 |
| **角度** | 自动提取 | 平视 / 仰拍 / 俯拍 / 低机位 / 高机位 / 倾斜镜头 |
| **运镜** | 自动提取 | 固定镜头 / 推镜 / 拉镜 / 跟拍 / 环绕 / 升降 / 高速追踪 / 手持 |
| **节奏** | 自动判断 | 慢镜头 / 中速 / 快速 / 高速剪辑 / 子弹时间 |
| **内容** | 核心内容总结（≤30字） | 月清寒突破冰剑洪流冲向霜映寒 |

**内容总结规则**：
- 控制在 30 字以内
- 提炼当前镜头最核心的动作/事件
- 简洁有力，符合电影分镜描述风格

- 分镜数量是否与输入一致
