## 发饰

### 簪子类

#### 玉簪 (Jade Hairpin)
- **描述**：玉制的发簪，温润典雅
- **特点**：素雅、温润、古典
- **适配风格**：江南、禅意、仙侠
- **英文描述**：jade hairpin, elegant, traditional

#### 金簪 (Gold Hairpin)
- **描述**：金制的发簪，华丽富贵
- **特点**：华丽、富贵、仪式感
- **适配风格**：宫廷、敦煌、仙侠
- **英文描述**：gold hairpin, ornate, luxurious

#### 银簪 (Silver Hairpin)
- **描述**：银制的发簪，清冷素雅
- **特点**：清冷、素雅、高级感
- **适配风格**：禅意、暗黑、江南
- **英文描述**：silver hairpin, cool-toned, minimalist

#### 木簪 (Wooden Hairpin)
- **描述**：木制的发簪，自然质朴
- **特点**：自然、质朴、禅意
- **适配风格**：禅意、侠客、江南
- **英文描述**：wooden hairpin, natural, rustic

### 步摇类

#### 金步摇 (Gold Tassel Hairpin)
- **描述**：带有流苏的金质发饰，行走时摇曳
- **特点**：华丽、灵动、富贵
- **适配风格**：宫廷、敦煌、仙侠
- **英文描述**：gold tassel hairpin, swaying tassels, ornate

#### 珍珠步摇 (Pearl Tassel Hairpin)
- **描述**：珍珠装饰的步摇，温婉典雅
- **特点**：温婉、典雅、女人味
- **适配风格**：江南、宫廷、仙侠
- **英文描述**：pearl tassel hairpin, elegant, feminine

#### 流苏步摇 (Tassel Hair Ornament)
- **描述**：长流苏装饰的发饰，飘逸灵动
- **特点**：飘逸、灵动、仙气
- **适配风格**：仙侠、敦煌、妖狐
- **英文描述**：tassel hair ornament, flowing, ethereal

### 发冠类

#### 凤冠 (Phoenix Crown)
- **描述**：皇后级别的发冠，凤凰造型
- **特点**：尊贵、华丽、仪式感

- **特点**：端庄、华贵、正式
- **适配风格**：宫廷
- **英文描述**：di crown, noble, formal

#### 莲花冠 (Lotus Crown)
- **描述**：莲花造型的发冠，仙气飘飘
- **特点**：仙气、出尘、宗教感
- **适配风格**：仙侠、禅意
- **英文描述**：lotus crown, celestial, spiritual

#### 银冠 (Silver Crown)
- **描述**：银制的发冠，清冷高贵
- **特点**：清冷、高贵、神秘
- **适配风格**：暗黑、仙侠、宫廷
- **英文描述**：silver crown, cool, regal

#### 项圈 (Collar Necklace)
- **描述**：项圈式项链，贴合颈部

### 手饰

## 各风格配饰搭配

### 仙侠风搭配
- **发饰**：玉簪 + 珍珠步摇 + 莲花冠
- **首饰**：璎珞项链 + 珍珠耳坠 + 玉手镯
- **特殊装饰**：披帛 + 花钿 + 玉佩
- **整体感觉**：仙气飘飘、温润典雅、不食人间烟火

### 敦煌风搭配
- **发饰**：金步摇 + 珠花 + 花钿
- **首饰**：多层璎珞项链 + 金耳坠 + 金色臂钏 + 金手镯
- **特殊装饰**：多条披帛 + 眉心坠 + 金腰带
- **整体感觉**：华丽雍容、异域风情、神性光辉

### 江南风搭配
- **发饰**：玉簪 + 珍珠步摇 + 简单发带
- **首饰**：珍珠项链 + 珍珠耳坠 + 玉手镯
- **特殊装饰**：宫绦 + 玉佩 + 流苏挂饰
- **整体感觉**：温婉贤淑、清丽脱俗、书卷气

### 宫廷风搭配
- **发饰**：凤冠/翟冠 + 金步摇 + 珠花 + 花钿
- **首饰**：项圈 + 金耳坠 + 金手镯 + 戒指
- **特殊装饰**：宫绦 + 玉佩组绶 + 香囊挂饰
- **整体感觉**：雍容华贵、端庄大气、仪式感

### 侠客风搭配
- **发饰**：发带 + 简单发簪 + 头巾
- **首饰**：简单项链 + 耳钉 + 护腕 + 皮手镯 + 简单戒指
- **特殊装饰**：斗篷 + 腰带 + 腰牌挂饰
- **整体感觉**：飒爽英姿、冷艳凌厉、江湖气

### 禅意风搭配
- **发饰**：木簪/银簪 + 无多余装饰
- **首饰**：简单玉镯 + 佛珠手链 + 无其他首饰
- **特殊装饰**：简约玉佩 + 无其他装饰
- **整体感觉**：宁静致远、淡雅脱俗、与世无争

### 妖狐风搭配
- **发饰**：红花发饰 + 金饰 + 凌乱美
- **首饰**：金耳坠 + 臂钏 + 戒指 + 金项链
- **特殊装饰**：面纱 + 彼岸花装饰 + 狐耳（可选）
- **整体感觉**：妖艳魅惑、神秘危险、勾魂夺魄

### 暗黑风搭配
- **发饰**：银饰 + 骨饰 + 黑色发饰
- **首饰**：银项链 + 银耳坠 + 银手镯 + 戒指
- **特殊装饰**：斗篷 + 锁链装饰 + 骷髅元素
- **整体感觉**：阴郁冷艳、神秘莫测、暗黑女王
