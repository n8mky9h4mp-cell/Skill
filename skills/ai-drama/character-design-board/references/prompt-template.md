# 角色设定板完整中文提示词模板（prompt-template）

画面采用版式配色体系（版式配色跟随角色配色方案，预设见 [color-palettes.md](color-palettes.md)；未指定时默认为黑金版式）：

整张设定板分为左侧角色信息区、中间三视图区、右侧细节展示区和底部配件展示区。

不要使用现代网页 UI 风格，不要出现按钮、滚动条、窗口边框、虚假软件界面或操作控件。

"CHARACTER DESIGN"

标题附近放置一个与角色属性有关的简洁图腾：

{{element_symbol}}

图腾采用金色线稿或金属浮雕效果，造型简洁，不能抢夺主体视觉。

左侧中部显示角色名字：

"{{character_name_cn}}"

角色名使用较大的金色中文艺术字体。

角色名下方显示：

"{{character_name_en}}"

英文名或罗马音使用较小的大写衬线字体，字母间距较宽。

角色基本信息区域显示：

性别：{{gender}}
年龄：{{age}}
身高：{{height}}
身份：{{identity}}
所属：{{organization}}
能力：{{element}}

基本信息使用整齐的左对齐排版，文字颜色为低饱和浅金色。

{{keywords_1}}
{{keywords_2}}
{{keywords_3}}

"{{color_scheme}}"

主色（Primary）：{{main_color}}
辅助色（Secondary）：{{secondary_color}}

配色方案栏目的颜色必须与角色实际服装、发色、饰品配色完全一致，不得出现栏目展示的颜色与角色身上颜色不符的情况。

人物采用自然直立站姿，双脚位置清晰，身体不可被裁切。

人物面向镜头站立，双手自然垂落或略微放松。

鞋必须完整露出（含鞋面、鞋底厚度、鞋后跟），裙摆不得遮挡鞋子全貌。
