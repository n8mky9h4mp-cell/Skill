# 预设配色方案库（color-palettes）

提供按世界观与气质分类的现成配色方案。用户可指定 `color_scheme` 变量为下列任一名称，或自定义配色。

每个方案给出：底色偏向 / 角色配色（主色 / 辅助色 / 点缀色 / 代表色，含 HEX + 占比）/ **版式配色（画板背景 / 标题 / 分隔线 / 边框）** / 适用角色气质。

> **面积占比**是建议的视觉分布比例，帮助 AI 控制颜色在画面中的权重：主色铺底，辅助色搭框架，点缀色用于细节高光，代表色用于色块展示。
>
> **版式配色**是设定板画板本身的颜色（背景、标题文字、分隔线、边框），须克制低饱和，作为画面骨架，不抢角色主体。每套角色配色自带一套协调的版式配色。

## 使用方式

1. 在变量表 `color_scheme` 字段填预设名（如 `cyber-neon`）或自定义。
2. 若选预设，自动套用对应的底色偏向、角色配色（主色 / 辅助色 / 点缀色 / 代表色）与**版式配色（画板背景 / 标题 / 分隔线 / 边框）**，**用户显式指定的颜色优先**。
3. 若自定义，用户自行填角色配色与 `layout_*` 版式变量，`color_scheme` 留空，版式默认使用黑金版式。
