# 图片素材与音频提示词

## 图片生成前

先建立素材清单，统一：

- 美术风格、视角、光照、线条和色板。
- 画布尺寸、目标显示尺寸、透明背景和安全边距。
- 角色比例、朝向、表情与跨图一致性。
- UI 状态：默认、按下、禁用、选中。
- 文件命名、导入目录、压缩和图集策略。

## 使用图片生成工具

- 当前环境有可用图片生成工具且用户允许时，按素材组生成角色、场景和 UI。
- 编辑已有图片前先查看原图，保持角色和风格一致。
- 生成结果保存到 PRD 约定路径，并记录提示词、来源、日期和用途。
- 检查透明边缘、裁切、文字错误、重复肢体、视觉一致性和实际游戏尺寸可读性。
- 工具不可用时使用程序绘制或临时素材验证玩法，并在进度和替换清单中标记。

## 音频交付

不自动生成或下载音效/BGM。创建 `docs/game/audio-prompts.md`：

```markdown
## [音频名称]
- 类型：BGM / UI / 反馈 / 环境
- 使用场景与触发：
- 建议时长：
- 是否无缝循环：
- 情绪与节奏：
- 乐器或声音材质：
- 音量层级：
- 避免元素：
- 建议文件名：
- 目标路径：
- 专业平台提示词：
```

提示词写完整生成要求，不包含无法证明拥有授权的音乐人模仿要求。用户生成文件后再检查时长、循环点、响度和许可证，并接入目标路径。

## 授权记录

图片、字体、角色、代码和后续音频都要记录来源、许可证或生成方式。不能把搜索预览图或来源不明素材直接放入可发布项目。
