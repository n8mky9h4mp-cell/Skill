# 发布准备与运营

## 发布边界

Skill 生成清单并协助准备产物，但不自动提交审核、发布、修改线上配置或操作开发者账号。

## 发布准备清单

按当前微信和抖音官方页面核对：

- 游戏名称、图标、简介、详细介绍和截图。
- 玩法说明、测试入口、测试账号或测试步骤。
- 版本号、更新说明和构建产物。
- 隐私说明、用户协议、适龄与未成年人相关信息。
- 主体、备案/审批咨询、软件著作权或其他版权材料。
- 图片、字体、角色、代码和音频授权记录。
- 广告位、奖励规则、失败行为和客服渠道。
- 真机验收记录与已知限制。

具体材料和资格随平台、主体、玩法和时间变化，记录查询日期与官方来源；不承诺“资料齐全就一定通过”。

## 首版指标

PRD 选择真正可采集且与目标相关的指标：

| 指标 | 用途 |
| --- | --- |
| 新增用户 | 入口与获量变化 |
| 次日留存 | 首日体验和继续游玩意愿 |
| 单局/每日时长 | 节奏与内容深度 |
| 关卡或单局完成率 | 难度与流失点 |
| 广告加载成功率 | 平台与网络稳定性 |
| 激励完成率 | 奖励吸引力与广告体验 |
| 崩溃率 | 客户端稳定性 |
| 资源加载失败率 | CDN、缓存与弱网质量 |

没有数据系统时，不为展示完整而虚构指标采集。需要远程统计或运营后台时，按后端决策门槛单独确认。

## 迭代循环

```text
观察数据 → 定位流失点 → 提出最小改动 → 内部验证
→ 提交新版本 → 灰度/小范围观察 → 再决定是否扩大
```

每次版本变化同步更新 PRD、任务、进度和变更记录。
