# 微信小游戏适配

## 官方入口

- [Cocos Creator 3.8 发布到微信小游戏](https://docs.cocos.com/creator/3.8/manual/en/editor/publish/publish-wechatgame.html)
- [微信小游戏开发文档](https://developers.weixin.qq.com/minigame/dev/guide/)

实现前打开当前版本文档，核对基础库、API、包体/分包、广告和审核规则。不要从旧教程复制限制数字或弃用接口。

## 构建准备

- 确认 Cocos Creator 精确版本和对应文档版本。
- 确认微信小游戏账号、App ID、开发者工具和体验权限。
- 在 Cocos 构建面板选择微信小游戏目标，使用项目实际方向和资源配置。
- 构建产物导入微信开发者工具后再验证平台能力。

## 适配重点

- `wx` 只出现在微信平台实现和必要的微信专属模块中。
- 登录 code 只发送给可信后端交换会话；没有后端时不要伪造完整账号系统。
- 分享结果按当前微信 API 语义处理，不假设用户操作一定可被可靠判定。
- 本地存储失败、空间不足和版本迁移要有降级或清理策略。
- 前后台、网络状态、安全区域和振动通过统一适配层通知游戏。
- Cocos 未完全适配的平台 SDK 能力需要项目自行封装并真机验证。

## 资源与分包

- 根据当前官方限制检查主包、分包、远程资源和缓存。
- 启动场景只依赖首屏必要资源。
- Asset Bundle 与平台分包配置保持一致，不能只在 Web 预览验证。
- 远程资源使用 HTTPS、合法域名和版本化路径，并测试下载失败与缓存清理。

## 验收

至少记录：开发者工具构建、预览/真机、登录、存储、分享、广告、前后台恢复、弱网和资源失败。没有 App ID 或真机时标记未执行，不写已通过。
