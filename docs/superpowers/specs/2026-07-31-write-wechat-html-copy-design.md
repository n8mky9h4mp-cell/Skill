# 微信公众号 HTML 富文本交付设计

## 背景

`write-wechat-articles` 当前生成 `article.md`、`wechat.md` 和 `assets.md`。其中 `wechat.md` 是公众号排版稿，但没有可直接检查的 HTML 源码，也无法通过单次操作把带样式的富文本复制到微信公众号编辑器。

本次调整需要同时满足两个目标：

1. `wechat.md` 保存完整、可一键复制的文章 HTML 源码，CSS 包含在源码内。
2. 用户可在本地预览最终排版，并把带样式的文章直接粘贴到微信公众号编辑器。

## 已确认决策

- 默认视觉采用 A「冷静技术编辑风」。
- `wechat.md` 只保留简短使用说明和一个完整的 `html` 代码块，不重复正文。
- 新增 `wechat.html`，用于真实排版预览和富文本复制。
- 图片继续使用可见占位符，由用户粘贴后从微信公众号素材库替换。
- 每篇文章固定生成 4 个文件。

## 输出结构

```text
articles/
└── YYYY-MM-DD-短标题/
    ├── article.md
    ├── wechat.md
    ├── wechat.html
    └── assets.md
```

文件职责：

- `article.md`：标题候选、摘要、Markdown 正文和参考资料。
- `wechat.md`：简短使用说明和一个包含完整文章片段的 `html` 代码块。
- `wechat.html`：独立预览页、复制操作区和与 `wechat.md` 一致的文章内容。
- `assets.md`：封面提示词、配图清单和图片占位符对应关系。

`wechat.md` 中保存的是文章 HTML 片段，不包含预览页按钮、页面外壳和交互脚本。`wechat.html` 将该文章片段放入独立预览页，并附加复制能力。

## HTML 与 CSS 策略

文章片段采用语义清晰、层级较浅的 HTML。所有影响文章正文的 CSS 均写入元素的 `style` 属性，不依赖：

- 外部样式表或字体
- CSS 类名
- CSS 变量
- 伪元素
- 动画或悬停状态
- 媒体查询
- 外部脚本

预览页自身的操作区可以使用独立的页面样式，但不得位于待复制的文章容器内。

代码内容必须转义 `&`、`<`、`>` 等 HTML 特殊字符。长代码使用自动换行策略，避免手机端出现横向溢出。

## 默认视觉规范

默认样式为克制的技术编辑风：

- 正文：16px，行高约 1.85，深灰色。
- 强调色：深蓝色，仅用于栏目标签、标题重点和细线。
- 标题：清晰加粗，无渐变、阴影和大面积装饰色块。
- 提示框：浅蓝底色配左侧细线。
- 代码块：深色背景、浅色文字、自动换行。
- 图片占位：浅色背景、细边框和明确编号。
- 段落：每段表达一个重点，保持适度留白。

技术教程、原理分析、故障复盘、工具评测、AI 漫剧、AI 音乐和提示词分享共用同一套基础样式，只允许按文章类型调整栏目标签和必要的内容组件。

## 富文本复制流程

`wechat.html` 顶部提供“复制到公众号”按钮。点击后：

1. 只读取文章容器内部内容。
2. 同时向剪贴板写入 `text/html` 和 `text/plain`。
3. 成功后显示明确状态，不改变文章内容。
4. 若浏览器不支持富文本剪贴板接口，则选中文章区域并尝试浏览器兼容复制。
5. 若兼容复制仍失败，则保留选中状态，并提示用户手动复制。

复制范围不得包含：

- 复制按钮
- 操作说明
- 成功或失败提示
- 预览页背景和外层布局
- 页面脚本

源文件与预览文件必须使用相同文章结构。生成时先完成文章 HTML 片段，再分别放入 `wechat.md` 和 `wechat.html`，不得独立改写两份正文。

## 图片处理

正文图片位置统一使用可见占位符：

```text
【配图 01｜用途｜建议比例｜替换为公众号素材库图片】
```

图片编号和位置必须在 `article.md`、`wechat.md`、`wechat.html` 与 `assets.md` 中保持一致。

占位符在 `wechat.html` 中使用浅色提示框展示。用户复制到公众号后，从素材库插入对应图片，再删除占位框。Skill 不自动上传素材，也不声称已完成上传。

## 验收方案

生成一篇包含以下组件的样稿：

- 栏目标签和文章标题
- 普通段落和二级标题
- 有序或无序列表
- 重点提示框
- 代码块
- 链接或参考资料
- 图片占位符
- 文末互动问题

检查：

- `wechat.md` 只有简短说明和一个完整 HTML 代码块。
- `wechat.html` 可独立打开且不依赖网络资源。
- 富文本复制不包含操作区。
- 富文本剪贴板接口不可用时，兼容复制或手动复制仍可完成操作。
- 代码已正确转义，长行不会撑破正文。
- 手机宽度下无横向溢出。
- 4 个文件中的正文信息和图片编号一致。
- Skill 元数据、目录结构和引用路径验证通过。
- 根目录说明与 `llms.txt` 已同步更新。
